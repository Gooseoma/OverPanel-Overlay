## Зачем нужен оверлей?

Оверлей необходим администраторам проектов, для удобного модерирования проектов, не заходя в панель

## Безопасность

Оверлей безопасен на 99%, оверлей не трогает процессы напрямую, и никак не лезет в работу системы
Easy AntiCheat (EAC) с вероятностью 99% не будет как либо мешать процессу оверлея, т.к это просмотр браузера

## Доступен ли всем оверлей?

Оверлей доступен только людям у которых есть проект в панели (не важно какая у вас должность там)
Авторизация в оверлее происходит напрямую через панель.
